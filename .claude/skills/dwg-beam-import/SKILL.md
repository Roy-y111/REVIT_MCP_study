# DWG 結構樑自動翻模

依據 `domain/dwg-beam-import.md` 執行。把 CAD 圖面的雙線樑批次轉成 Revit 結構樑。

**鐵則：建樑不可自動復原，逐步走斷點、每步取得同意，絕不可以一口氣跑完。**

## Prerequisites（先確認，缺則停止並告知）
- Revit 開在**平面視圖**（三個工具都要求 `ViewPlan`）。
- 目標 CAD 已**匯入或連結**到該視圖。
- 專案已**載入目標結構樑族群**。
- 樑輪廓與文字標注畫在**獨立圖層**（靠圖層名識別）。

## Sub-Workflows (強制斷點)

### 1. 掃描圖層 ⛔ 斷點
呼叫 `get_dwg_beam_layers` 掃描圖面。
向使用者回報視圖名稱、CAD 數量與推薦樑圖層，並**必須停下來依序詢問**：
1. 這次先處理哪個批次？（大樑 / 次樑 / 地樑）
2. 翻模模式：
   - **模式 A（快速）**：指定統一型別，全部套用，不需要文字圖層
   - **模式 B（名稱對應）**：依圖面文字自動配對 Revit 型別

### 2. 依模式收集參數 ⛔ 斷點
- **若為模式 A**：詢問族群名稱 + 統一型別名稱（如 `50x70`）。
- **若為模式 B**：詢問文字圖層（X 向與 Y 向）與族群名稱。
**必須停下來等待使用者提供參數，確認後再繼續。**

### 3. 放樣健檢（自動接續）
呼叫 `preview_dwg_beams`，向使用者回報偵測樑數、斜向數量、樑寬範圍，然後直接繼續下一步。

### 4. 批次建樑 ⛔ 執行前複述參數取得同意
執行前，向使用者複述即將執行的參數並取得同意。
呼叫 `create_beams_from_dwg`，**必須強制將 `beamRole` 寫入參數**。

**內部兩波機制（斜樑防呆）：**
- 第一波：正交樑優先配對，消耗標籤進 `usedLabelKeys`
- 第二波：斜樑用剩餘標籤，點到線段距離配對（閾值 = 樑寬/2 + 500mm）

**回傳檢查：**
| 現象 | 處理 |
|---|---|
| `unmatchedLabels` 不為空 | 停下協作：族群缺對應型別？ |
| `failed > 0` 且 `unmatchedLabels` 為空 | 樑端點問題（太短/無支撐），手動補 |
| `labelReadStatus = no_oda` | 安裝 ODA File Converter 或改用 DXF |

### 5. 詢問下一批次
完成後詢問：是否繼續處理下一批次？（大樑 → 次樑 → 地樑）

## 工具
| 工具名稱 | 用途 |
|---------|------|
| `get_dwg_beam_layers` | 掃描視圖中的 CAD 檔案並回報推薦的樑與文字圖層 |
| `preview_dwg_beams` | 預覽即將建置的樑數量、寬度與方向 |
| `create_beams_from_dwg` | 執行 Revit 實體樑建置（必須帶入 beamRole） |

## Error Handling
| 症狀 | 處理 |
|---|---|
| 「請在平面視圖中執行」 | 切換至平面視圖 |
| 圖層清單為空 | 確認 CAD 已匯入/連結且可見 |
| preview 數量為 0 | 換圖層或確認樑為雙線且寬度在 100–2500mm |
| 「找不到族群」 | 先載入結構樑族群 |
